# Tayba Theme for ERPNext

A clean, high-visibility modern theme for ERPNext Desk with a slate sidebar and refined typography.

## Features
- **High-Visibility Sidebar**: Crisp, readable off-white typography and soft silver icons.
- **Card Styling**: Clean borders and soft elevation for workspace cards and dashboard widgets.
- **Universal**: Applies automatically to all devices (desktop, tablet, mobile) and all users across the Frappe site.

## Installation on Frappe Cloud
1. In Frappe Cloud dashboard, navigate to your Bench.
2. Click **Apps** > **Add App**.
3. Enter this GitHub repository URL.
4. Deploy the bench and install the app on your site.
